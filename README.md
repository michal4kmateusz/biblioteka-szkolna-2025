# Biblioteka Szkolna 2025 – System zarządzania wypożyczeniami

**Najładniejsza i najbardziej funkcjonalna aplikacja biblioteki szkolnej napisana w 100% samodzielnie w Pythonie.**

### Funkcje
- Wypożyczanie i zwroty jednym kliknięciem
- Automatyczne kary za przetrzymanie (1 zł/dzień)
- Eksport do PDF (ReportLab) – otwiera się automatycznie
- Żywa wyszukiwarka
- Dodawanie nowych uczniów i książek w locie
- Płynne przewijanie (scroll działa idealnie!)
- Nowoczesny design (gradient, zegar, dźwięki)
- Statystyki aktywne/przetrzymane na żywo
- Małe, eleganckie przyciski WYPOŻYCZ / ODDAJ

### Technologie
- Python 3 + Tkinter
- ReportLab (PDF)
- winsound (dźwięki)
- JSON (dane w pamięci)

### Jak uruchomić
```bash
python biblioteka_szkolna_2025.py
